O campo NÃO é travado: também permite digitar outra central.

2. ENTER ENTRE CAMPOS
Nos formulários funcionais:
- Clientes
- Doadoras
- Touros
- Raças
- Aspiração
- Produção

Enter avança para o próximo campo.
No último campo, Enter chega ao botão Salvar.

3. ASPIRAÇÃO DE OÓCITOS
Funcional:
- Data
- Cliente
- Doadora filtrada pelo cliente
- G1, G2, G3, G4, G5
- Clientes minimizados
- Pesquisa
- Editar / Excluir

4. PRODUÇÃO AUTOMÁTICA
Ao salvar a Aspiração:
- cria produção por Cliente + Data + Doadora
- Oócitos totais = G1 + G2 + G3 + G4
- Oócitos viáveis = G1 + G2 + G3

Na Produção você completa:
- Touro (somente touros daquele cliente)
- Clivados
- Embriões D7
- Fresco
- DT
- VT
- Observações

5. PRODUÇÃO AGRUPADA
Cliente + Data ficam como pasta minimizada.

COMO ABRIR
1. Extraia a pasta EmbrioGestor_2_0_FASE3
2. Abra essa pasta no VS Code
3. Terminal:
   npm install
4. Depois:
   npm run dev
5. Abra http://localhost:5173/

Não substituir ainda o EmbrioGestor oficial.
