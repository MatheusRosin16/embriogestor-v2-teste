EMBRIOGESTOR 2.0 — FASE 10.1 — GESTÃO ECONÔMICA DA PIVE

Substitui o indicador único de custo por uma análise em níveis.

ESTRUTURA
- Custos fixos
- Custos variáveis
- Depreciação
- Custos por categoria
- Custos opcionais vinculados a um cliente
- Custos compartilhados do laboratório

INDICADORES
- Custo por OPU
- Custo por oócito viável
- Custo por embrião D7 (indicador de produção laboratorial)
- Custo por embrião destinado (Fresco + DT + VT)
- Custo por prenhez (quando houver DG positiva e custo adicional TE/receptoras)
- Taxa de produção D7/viáveis
- Margem estimada
- Ponto de equilíbrio

RATEIO POR CLIENTE
- Custo direto: lançamento vinculado ao cliente
- Compartilhado: rateado proporcionalmente aos embriões D7 do mês

COMPATIBILIDADE
Os custos antigos continuam válidos e são interpretados como custos Variáveis quando não possuem o novo campo Tipo.

TESTE
npm install
npm run dev
