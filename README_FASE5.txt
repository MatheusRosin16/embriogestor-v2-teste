EMBRIOGESTOR 2.0 — FASE 5

FUNCIONAL NESTA FASE
- Estoque de Sêmen por cliente/touro/partida
- Saldo automático e localização CANECA/BOTIJÃO
- Uso de doses na Produção baixa o estoque quando encontra Cliente + Touro + Partida
- Estoque de Embriões DT/VT por cliente
- Congelados DT/VT da Produção geram/ajustam estoque automaticamente quando há touro definido
- Movimentações automáticas de entradas, saídas e ajustes
- Pesquisa digitável e clientes minimizados
- Enter mantido nos formulários

COMO ABRIR
1. Extraia EmbrioGestor_2_0_FASE5
2. Abra a pasta interna no VS Code
3. npm install
4. npm run dev
5. Abra http://localhost:5173/
