EMBRIOGESTOR 2.0 — FASE 14.13.1
ANÁLISE DE TOUROS POR PARTIDA

- Base: Fase 14.13 confirmada pelo usuário.
- Remove Cliente e Central da Análise de Touros.
- Adiciona Partida.
- Cada combinação Touro + Partida ocupa uma linha.
- A mesma partida do mesmo touro usada por clientes diferentes é consolidada na mesma linha.
- Partidas diferentes do mesmo touro ficam em linhas diferentes.
- Mantém filtros de período e pesquisa por touro, partida ou raça.
- Não altera login, acessos, Dashboard ou demais módulos.

Observação de dados: a Produção não armazena partida diretamente; a análise relaciona a partida pelo registro de Sêmen utilizado no serviço (cliente + data + touro). Se houver mais de uma partida do mesmo touro registrada no mesmo cliente/data, os dados existentes não permitem identificar qual produção individual pertenceu a qual partida.
