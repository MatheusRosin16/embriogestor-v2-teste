EMBRIOGESTOR 2.0 — FASE 14.4 — DASHBOARD RESPONSIVO

Base: Fase 14.3 estável.

ALTERAÇÕES DESTA FASE
- Dashboard reorganizado na disposição operacional do sistema antigo.
- Tipografia aumentada para melhor leitura no computador e no celular.
- Filtro do Dashboard por Ano, Mês ou Todos.
- Regra de OPU mantida: 1 cliente + 1 data = 1 OPU/produção de serviço.
- Várias doadoras do mesmo cliente na mesma data não aumentam o número de OPUs.
- Oócitos viáveis, oócitos totais, Embriões D7, frescos, DT, VT e transferências.
- Total de congelados = somente Congelados DT + Congelados VT das produções.
- Estoque de sêmen não participa do total de embriões congelados.
- Gráfico Produções por mês usando a mesma regra cliente + data.
- Últimas produções agrupadas por cliente + data.
- Layout responsivo para desktop, tablet e celular.

NÃO FOI FEITO AINDA
- Redirecionamento ao clicar nos cards.
- Redirecionamento de uma produção recente para a tela específica.
Esses atalhos serão adicionados posteriormente, conforme solicitado.
