EmbrioGestor 2.0 — Fase 14.15 — Digitalizar Ficha de Transferência

Base: Fase 14.14 PWA Offline.

Incluído:
- Novo menu “Digitalizar Ficha de TE” para ADMIN e VETERINARIO.
- No celular: botão Tirar foto usa a câmera traseira quando suportado.
- Também aceita escolher imagem e selecionar PDF.
- Guarda/mostra prévia da foto no aparelho.
- Gera uma prévia editável e permite adicionar/excluir/corrigir linhas.
- Salva o resultado como Relatório Transferência Editável, sem baixar estoque.
- Estrutura preparada para o modelo fornecido: Propriedade, Doadora, Touro, Raça, Embrião, Receptora, CL, DG30 e DG60.
- Nenhuma leitura de imagem é inventada: o conector OCR/IA online ainda precisa ser configurado na publicação.
- Nenhuma alteração em login, perfis ou permissões.
- A ficha não cria transferência oficial nem movimenta estoque automaticamente.

Conectar o botão “Ler ficha e gerar rascunho” a um serviço OCR/IA via backend seguro. Chaves de API nunca devem ficar no navegador.
