EMBRIOGESTOR 2.0 — FASE 4

ALTERAÇÕES NA PRODUÇÃO

1. NOVA PRODUÇÃO
Agora existe o botão "Nova produção" no topo.

Pode criar produção manual com:
- Data
- Cliente
- Doadora
- Oócitos totais
- Oócitos viáveis
- Touro (opcional no início)
- Clivados
- D7
- Fresco
- DT
- VT
- Observações

2. PRODUÇÃO POR CLIENTE + DATA
Continua organizada em pasta Cliente + Data.

3. SÊMEN UTILIZADO NO SERVIÇO
Abaixo da tabela de cada data existe:
"Sêmen utilizado no serviço"

Com botão:
"Registrar doses do serviço"

Campos:
- Touro
- Raça automática
- Partida/lote
- Doses
- Observações

4. TOURO POR DATA / SERVIÇO
O sêmen registrado fica vinculado ao Cliente + Data.

Ao registrar o touro do serviço, ele é aplicado automaticamente
às produções daquela data que ainda estiverem SEM touro.

Se alguma doadora já estiver com touro específico, ele não é substituído.

5. PARTIDA
Se o banco já possuir estoque de sêmen importado/cadastrado,
o campo partida oferece as partidas encontradas para:
Cliente + Touro.

Também pode digitar manualmente.

6. ENTER
Enter continua avançando os campos também nos novos formulários.

COMO ABRIR
1. Extraia EmbrioGestor_2_0_FASE4
2. Abra a pasta interna no VS Code
3. npm install
4. npm run dev
5. Abra http://localhost:5173/
