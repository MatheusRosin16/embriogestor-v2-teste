EMBRIOGESTOR 2.0 — PROJETO NOVO

ESTA PASTA É TOTALMENTE NOVA.
Não substitua o EmbrioGestor oficial ainda.

COMO ABRIR:

1. Extraia o ZIP.
2. Abra a pasta EmbrioGestor_2_0_NOVO no VS Code.
3. Abra Terminal > New Terminal.
4. Execute:

npm install

5. Quando terminar:

npm run dev

6. Abra no navegador:

http://localhost:5173/

Se o terminal mostrar outro endereço, use o endereço mostrado pelo Vite.
