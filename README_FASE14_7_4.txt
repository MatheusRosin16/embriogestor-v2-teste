EMBRIOGESTOR 2.0 — FASE 14.7.4 — PRODUÇÃO GERA ASPIRAÇÃO AUTOMÁTICA

- Ao cadastrar uma Produção diretamente, se não existir Aspiração para cliente + doadora + data, o sistema cria uma automaticamente.
- A Aspiração automática recebe os Oócitos totais e Oócitos viáveis informados na Produção.
- G1, G2, G3, G4 e G5 ficam em zero.
- Aspirações automáticas são identificadas na tela.
- Se já existir Aspiração para cliente + doadora + data, nenhuma duplicata é criada.
- Ao editar uma produção ligada a Aspiração automática, totais e viáveis permanecem sincronizados.
- Dashboard passa a considerar totais/viáveis informados nas Aspirações automáticas.
- Aspirações classificadas manualmente continuam usando G1+G2+G3 como viáveis e G1+G2+G3+G4 como totais.
