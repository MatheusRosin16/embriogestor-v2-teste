EMBRIOGESTOR 2.0 — FASE 2

FUNCIONAL NESTA VERSÃO:
- Clientes: criar, editar, excluir, pesquisar
- Doadoras: criar, editar, excluir, pesquisar
- Doadoras minimizadas por cliente
- Touros: criar, editar, excluir, pesquisar
- Touros minimizados por cliente
- Tipo de sêmen: Convencional / Sexado macho / Sexado fêmea
- Raças: criar, editar, excluir
- Abreviatura editável
- Correções padrão:
  Brangus = BN
  Nelore = NE
- Importação do JSON antigo continua disponível
- Tudo salva no localStorage da nova versão

COMO USAR:
1. Extraia este ZIP em uma pasta NOVA.
2. Abra EmbrioGestor_2_0_FASE2 no VS Code.
3. Terminal:
   npm install
4. Depois:
   npm run dev
5. Abra:
   http://localhost:5173/

IMPORTANTE:
Não substitua ainda o EmbrioGestor oficial.
